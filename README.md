# Windows Support 

Hands-on Windows troubleshooting labs for Junior Systems Engineer preparation.

## Objective

Practice real-world Windows troubleshooting by creating controlled problems, diagnosing the root cause, applying a solution, and verifying the results.

## Troubleshooting Methodology

1. Identify the problem
2. Gather information
3. Isolate the cause
4. Test a hypothesis
5. Apply the solution
6. Verify the fix
7. Document the resolution
